# Write a numeric value into the current row of a CSV

Write a numeric value into the current row of a CSV

## Usage

``` r
csv_writer_print_double(writer_ptr, column, value)
```

## Arguments

- writer_ptr:

  External pointer to a CsvWriter object.

- column:

  Column name.

- value:

  Numeric value.

## Value

Called for side effects; returns invisibly.
