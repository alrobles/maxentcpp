# Enable or disable streaming-eval mode on a FeaturedSpace

Enable or disable streaming-eval mode on a FeaturedSpace

## Usage

``` r
maxent_set_streaming_eval(fs_ptr, enabled = TRUE)
```

## Arguments

- fs_ptr:

  External pointer to a FeaturedSpace object.

- enabled:

  Logical flag.

## Value

Called for side effects; returns invisibly.
